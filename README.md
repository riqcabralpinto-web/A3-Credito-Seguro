# Crédito Seguro - Frontend

Interface web educativa e simulador do sistema **Modo Rua** — uma solução de proteção bancária por geolocalização.

## 🎯 Sobre o Projeto

Projeto educacional desenvolvido para conscientizar sobre fraudes financeiras (principalmente o golpe da taxa antecipada) e demonstrar na prática como funciona um sistema de segurança baseado em localização.

## ✨ Funcionalidades

- Página institucional com conteúdo sobre prevenção de fraudes
- Simulação completa de um aplicativo bancário
- Cadastro com definição de zona segura no mapa
- Login com verificação de localização em tempo real
- Bloqueio de acesso quando fora da zona segura
- Acesso de emergência via código OTP
- Gerenciamento de zonas seguras e alertas de segurança
- Alternância entre tema claro e escuro no app bancário

## 🛠️ Tecnologias Utilizadas

- HTML5, CSS3 e JavaScript (Vanilla)
- Leaflet.js + OpenStreetMap
- Nominatim API (busca de endereços)
- Lucide Icons
- Fetch API para integração com o backend

> **Importante:** O backend deve estar rodando para que o cadastro, login e funcionalidades completas funcionem.
